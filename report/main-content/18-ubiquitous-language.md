## 2.5. Ubiquitous Language

1. **Pharmaceutical Laboratory** (Laboratorio Farmacéutico)

   **Definición:** Establecimiento en el que se realizan actividades relacionadas con el desarrollo, fabricación, análisis, control o evaluación de productos farmacéuticos, bajo procedimientos y condiciones definidas para garantizar su calidad.

2. **Pharmaceutical Warehouse** (Almacén Farmacéutico)

   **Definición:** Área destinada a la recepción, conservación y almacenamiento de materias primas, insumos o productos farmacéuticos bajo condiciones establecidas que permitan preservar su calidad.

3. **Controlled Area** (Área Controlada)

   **Definición:** Espacio del laboratorio o almacén en el que una o más condiciones ambientales deben mantenerse dentro de parámetros establecidos de acuerdo con las actividades, materiales o productos presentes en dicha área.

4. **Environmental Condition** (Condición Ambiental)

   **Definición:** Estado del ambiente de un área determinada, evaluado mediante variables como temperatura, humedad y presión diferencial, según los requerimientos establecidos.

5. **Environmental Variable** (Variable Ambiental)

   **Definición:** Magnitud utilizada para evaluar las condiciones ambientales de un área. Las principales variables identificadas son temperatura, humedad y, cuando corresponde, presión diferencial.

6. **Environmental Parameter** (Parámetro Ambiental)

   **Definición:** Criterio o valor establecido para una variable ambiental de acuerdo con las características del área, proceso o producto que se encuentra bajo supervisión.

7. **Acceptable Range** (Rango Aceptable)

   **Definición:** Intervalo de valores permitido para una variable ambiental dentro de un área determinada. Una medición dentro de este intervalo se considera conforme con las condiciones establecidas.

8. **Environmental Measurement** (Medición Ambiental)

   **Definición:** Valor obtenido de una variable ambiental en un momento determinado y asociado al área en la que fue realizada la medición.

9. **Monitoring Schedule** (Horario de Monitoreo)

   **Definición:** Frecuencia o conjunto de horarios establecidos para verificar y registrar las condiciones ambientales de un área. Puede variar según el área, su uso y los procedimientos aplicables.

10. **Environmental Monitoring** (Monitoreo Ambiental)

    **Definición:** Proceso de supervisión de las variables ambientales de un área para comprobar que se mantengan dentro de los parámetros y rangos establecidos.

11. **Thermohygrometer** (Termohigrómetro)

    **Definición:** Instrumento utilizado para medir principalmente la temperatura y la humedad de un ambiente durante las actividades de control ambiental.

12. **Calibration** (Calibración)

    **Definición:** Proceso mediante el cual se verifica que un instrumento de medición proporcione resultados confiables y acordes con los criterios establecidos para su utilización.

13. **Correction Factor** (Factor de Corrección)

    **Definición:** Valor que debe considerarse al interpretar la lectura obtenida de un instrumento de medición cuando su calibración determina la necesidad de realizar un ajuste sobre el valor observado.

14. **Environmental Deviation** (Desviación Ambiental)

    **Definición:** Situación en la que una variable ambiental se encuentra fuera del rango o de los parámetros establecidos para un área determinada.
