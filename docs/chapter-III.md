# Capítulo III: Requirements Specification

En este capítulo se especifican los requisitos funcionales y técnicos de **QualiTrack**, considerando las necesidades identificadas para los responsables de calidad y supervisión, el personal operativo de laboratorios y almacenes farmacéuticos, así como los visitantes interesados en conocer la solución.

Las historias de usuario han sido organizadas en Epics que representan las principales capacidades de la solución. Cada User Story sigue la estructura **Como [actor], quiero [objetivo], para [beneficio]**, buscando expresar una necesidad desde la perspectiva del usuario y no desde la implementación técnica.

Asimismo, se incluyen Technical Stories para aquellos componentes que no representan una interacción directa con el usuario, pero que son necesarios para el funcionamiento de la solución distribuida, como los servicios REST, el Edge Service, la comunicación con los dispositivos IoT y las integraciones con servicios externos.

Los criterios de aceptación han sido planteados mediante escenarios utilizando la estructura **Dado / Cuando / Entonces**, permitiendo establecer condiciones claras y verificables para determinar cuándo una historia puede considerarse correctamente implementada.

## 3.3. Product Backlog

El Product Backlog de QualiTrack organiza las User Stories y Technical Stories según el valor que aportan al producto y al proceso de validación de la solución.

Se priorizan inicialmente las historias relacionadas con el **Landing Page**, debido a que permiten comunicar y validar tempranamente la propuesta de valor. Posteriormente se incluyen las capacidades necesarias para registrar organizaciones y áreas, configurar dispositivos IoT, recopilar telemetría, ejecutar acciones automáticas, generar alertas y analizar la información.

Las funcionalidades complementarias de reportes, suscripciones e integraciones se incorporan progresivamente a medida que las capacidades principales del producto se encuentran disponibles.

Para la estimación se utiliza la escala de Story Points **1, 2 y 3**.
